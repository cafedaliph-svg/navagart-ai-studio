# Navagart AI Studio

Aplicación de escritorio para Windows orientada a creación multimedia con IA: imagen, vídeo, referencias visuales, movimientos de cámara y proveedores locales/remotos.

## Estado

V0.1 en desarrollo.

## Stack

- Tauri 2
- React + TypeScript
- Vite
- Rust (shell desktop)
- Arquitectura de proveedores preparada para motores locales y APIs

## Objetivos V0.1

- Text to Image
- Image to Image
- Text to Video
- Image to Video
- Selector de modelo y proveedor
- Aspect ratios 16:9, 9:16 y 1:1
- Duración, seed y FPS
- Presets de cámara
- Cola de generación
- Galería/proyectos locales
- Build instalable para Windows

> Navagart AI Studio es un proyecto independiente y no está afiliado con Higgsfield AI.
